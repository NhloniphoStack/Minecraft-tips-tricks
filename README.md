# Minecraft Tips

A community-driven Minecraft tips platform where players can discover, share, and learn useful gameplay advice.

## Features

- Browse tips across different categories.
- Submit community-created tips.
- Moderation and approval before publication.
- Step-by-step gameplay instructions.

## Tech Stack

- Next.js
- TypeScript
- PostgreSQL
- Neon

## Getting Started

### Prerequisites

- Node.js
- npm
- PostgreSQL database

### Installation

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_NAME
npm install
```

### Environment Variables

Create a `.env.local` file in the project root:

```env
DATABASE_URL="your_database_connection_string"
```

### Run Locally

```bash
npm run dev
```

Open http://localhost:3000.

## Deployment

Deploy using Vercel and configure your PostgreSQL connection string in the project environment variables. Neon can be used as the PostgreSQL provider.
